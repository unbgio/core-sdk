# Model licenses

The MIT license in `LICENSE` covers the UNBG source code only. It does not
grant rights to model weights downloaded or bundled by the installer.

| Model | Upstream terms | Practical requirement |
| --- | --- | --- |
| [BRIA RMBG-1.4](https://huggingface.co/briaai/RMBG-1.4) | BRIA RMBG-1.4 license; non-commercial use under the upstream terms | Obtain a separate BRIA agreement before commercial use or redistribution |
| [BRIA RMBG-2.0](https://huggingface.co/briaai/RMBG-2.0) | CC BY-NC 4.0 for non-commercial use; gated download | Accept the upstream terms and obtain a separate BRIA agreement before commercial use or redistribution |

Review the current upstream model card and license before downloading,
shipping, or using either model. A Hugging Face access token proves access; it
does not by itself grant commercial rights. UNBG release artifacts should not
embed either model unless the distributor has confirmed the necessary rights.
